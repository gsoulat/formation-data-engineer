## Prérequis

- Terminal (macOS/Linux ou WSL2 sur Windows)
- Node.js >= 18 installé
- Compte Anthropic avec une clé API (ou abonnement Claude Max/Pro)
- Connaissances basiques en Git
- Un éditeur de code (VS Code recommandé)

## Objectifs finaux

A l'issue de cette formation, vous serez capable de :

- Installer et configurer Claude Code dans n'importe quel environnement
- Naviguer et modifier n'importe quel codebase efficacement
- Automatiser vos workflows Git (commits, PRs, reviews)
- Créer des fichiers CLAUDE.md pour contextualiser vos projets
- Écrire des prompts avancés pour des résultats précis
- Connecter des serveurs MCP pour étendre les capacités
- Automatiser des pipelines avec le mode headless
- Atteindre une productivité "divine" avec les patterns experts
