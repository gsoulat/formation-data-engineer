# Briefs — Parcours Data Analyst (28 semaines)

Le parcours fonctionne au rythme d'**un brief par semaine**, articulé avec le module
[15-Business-Intelligence](../../15-Business-Intelligence/) et le parcours
[PATH_DATA_ANALYST](../../PATH_DATA_ANALYST.md) :

- **Briefs hebdomadaires** ([`briefs-hebdo/`](briefs-hebdo/)) — un brief complet par semaine
  (contexte NordRetail, travail par étapes, livrables, critères), ciblé sur le module de la semaine.
- **Projets capstone de phase** (`BRIEF_*.md`) — projets de synthèse en fin de phase (🏁),
  qui assemblent les acquis. Le dernier est le **projet final de bout en bout**.

> **Données pour les TP** : [`data/`](data/) — univers **NordRetail** (voir le `README` du dossier).

## Progression pédagogique
Chaque brief hebdomadaire prépare le projet capstone de sa phase : les savoir-faire sont
d'abord travaillés isolément (découvrir → adapter), puis assemblés et menés en autonomie dans
le projet de fin de phase, jusqu'au projet final de bout en bout.

> dans le dépôt privé `formation-corrections`.
