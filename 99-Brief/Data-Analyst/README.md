# Briefs & missions — Parcours Data Analyst (28 semaines)

Deux niveaux de mise en situation, articulés avec le module
[15-Business-Intelligence](../../15-Business-Intelligence/) et le parcours
[PATH_DATA_ANALYST](../../PATH_DATA_ANALYST.md) :

- **Missions hebdomadaires** ([`missions-hebdo/`](missions-hebdo/)) — courtes (1-2 jours), une par
  semaine, ciblées sur le(s) module(s) de la semaine.
- **Projets fil rouge de phase** (`BRIEF_*.md`) — gros projets au format complet (contexte,
  modalités, critères par compétence), à la fin de chaque phase. Le dernier est le **projet
  certificatif BC06**.

> **Données pour les TP** : [`data/`](data/) (univers NordRetail — voir le `README` du dossier).
> Certification visée : **RNCP-38616**, option Data Analyse, bloc **BC06**.

## Progression pédagogique
Chaque mission hebdo (niveau *imiter / adapter*) prépare le projet fil rouge de sa phase ; les
compétences sont assemblées et *transposées* dans le projet de fin de phase, jusqu'au projet
certificatif BC06 (niveau 3, autonomie complète).
