# 🤖 Module 7 - BERT & GPT

Les modèles révolutionnaires qui dominent le NLP moderne

## 🚀 Révolution des Modèles Pré-entraînés

### 💥 Changement de Paradigme

BERT (2018) et GPT (2018-2023) ont révolutionné le NLP en introduisant les **modèles pré-entraînés** : entraînés sur d'énormes corpus, puis fine-tunés pour des tâches spécifiques.

**Avant (2017) :** Entraînement from scratch pour chaque tâche  
**Après (2018+) :** Pré-entraînement + Fine-tuning  
→ Performance révolutionnaire avec moins de données !

### ⚡ BERT vs GPT

Deux approches complémentaires qui dominent le NLP : BERT pour la **compréhension**, GPT pour la **génération**.

**BERT :** Bidirectionnel, Masking, Compréhension  
**GPT :** Autorégressif, Génération, Conversation  
→ Ensemble, ils couvrent tout le spectre NLP !
