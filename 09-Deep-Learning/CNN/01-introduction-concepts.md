## 🤖 Introduction au Deep Learning

### 🧠 Qu'est-ce que le Deep Learning ?
Le **Deep Learning** (apprentissage profond) est une sous-catégorie du Machine Learning qui utilise des réseaux de neurones artificiels avec de nombreuses couches pour modéliser et comprendre des données complexes.

### 🔍 Qu'est-ce qu'un CNN ?
Un **Réseau de Neurones Convolutionnel (CNN)** est un type spécialisé de réseau de neurones, particulièrement efficace pour traiter des données ayant une structure spatiale, comme les images.

### 🏗️ Architecture Typique d'un CNN
**Image d'entrée** → **Convolution** → **Activation** → **Pooling** → **Classification**

### 🎯 Intuition : Comment un CNN "Voit"
- **Couches Basses :** Détectent des bords, des coins, des lignes.
- **Couches Moyennes :** Combinent les bords pour former des motifs (oreilles, yeux).
- **Couches Hautes :** Assemblent les motifs pour reconnaître l'objet complet (chat).
