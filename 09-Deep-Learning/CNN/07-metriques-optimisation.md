## 📈 Évaluation du Modèle

### Lecture des Métriques
- **Accuracy** : Précision globale.
- **Loss** : Mesure de l'erreur.
- **Validation Metrics** : Évaluation sur données non vues.

### Diagnostic
- **Overfitting** : Excellente accuracy train, faible accuracy val.
- **Underfitting** : Performance faible sur les deux.

### Amélioration
- Augmentation de données.
- Ajustement du learning rate.
- Early stopping.
