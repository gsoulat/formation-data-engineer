# Veille Technologique

## Présentation du module

La **veille technologique** est une compétence fondamentale pour tout professionnel de la data et du développement. Dans un secteur où les outils, les frameworks et les paradigmes évoluent à grande vitesse, rester informé n'est pas une option — c'est une nécessité professionnelle.

Ce module vous enseigne à organiser, pratiquer et valoriser votre veille de manière systématique et efficace.

---

## Objectifs pédagogiques

À l'issue de ce module, vous serez capable de :

- Expliquer ce qu'est la veille technologique et pourquoi elle est stratégique
- Identifier les sources d'information pertinentes pour votre domaine
- Organiser votre flux d'information avec des outils adaptés (RSS, Notion, Obsidian)
- Rédiger un rapport de veille structuré et lisible
- Utiliser les LLMs pour accélérer et enrichir votre veille

## Pourquoi apprendre la veille dès maintenant ?

En formation data engineering, vous apprenez les technologies actuelles. Mais dans 2 ans, une partie de ces outils aura évolué, certains auront été remplacés, et de nouvelles catégories seront apparues. La veille technologique est la compétence qui vous permet de continuer à progresser après la formation, de manière autonome et structurée.

> "Ce n'est pas la technologie que vous connaissez aujourd'hui qui fera votre valeur dans 5 ans, c'est votre capacité à apprendre les prochaines."
