# 🧠 Algorithmie — Fondamentaux pour le Data Engineer

## 🎯 Objectifs pédagogiques

À l'issue de ce cours, vous serez capable de :

- ✅ Comprendre ce qu'est un algorithme et savoir en écrire en pseudo-code
- ✅ Analyser la complexité algorithmique (notation Big O)
- ✅ Maîtriser les structures de données fondamentales (listes, piles, files, arbres, graphes, tables de hachage)
- ✅ Implémenter et comparer les principaux algorithmes de tri
- ✅ Appliquer des algorithmes de recherche adaptés au contexte
- ✅ Comprendre la récursivité et la programmation dynamique
- ✅ Résoudre des problèmes de graphes courants en data engineering
- ✅ Comprendre les patterns d'architecture logicielle (MVC, multicouche, hexagonale, Clean)

## 📋 Prérequis

- Python : syntaxe de base (variables, boucles, fonctions, classes)
- Notions de mathématiques : fonctions, logarithmes, puissances

## 💡 Pourquoi l'algorithmie pour un Data Engineer ?

> L'algorithmie est le socle de la pensée computationnelle. Un Data Engineer qui comprend la complexité algorithmique saura :
> - Choisir la bonne structure de données pour un pipeline
> - Optimiser des traitements sur de grands volumes
> - Comprendre les mécanismes internes de Spark, Pandas ou SQL
> - Résoudre des problèmes de dépendances entre tâches (graphes DAG)
> - Écrire du code performant plutôt que naïf
